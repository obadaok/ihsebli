# احسب لي 🤖

مساعد محاسبي يعمل عبر واتساب لمتابعة عمليات شراء الذهب وتحويلات البنك.

## التشغيل محلياً

يتطلب: Node.js 18+ و tesseract (مع لغتي ara و eng).

```bash
npm install
npm run dev
```

امسح رمز QR المعروض من واتساب (الإعدادات ← الأجهزة المرتبطة).

## التشغيل على Render

1. ارفع هذا المشروع إلى GitHub.
2. في Render: **New → Blueprint** واختر مستودع `ihsebli`.
3. `render.yaml` جاهز: سيستخدم خطة **free** ويبني عبر Dockerfile.

> **ملاحظة عن التخزين:** خطة Render المجانية **لا تدعم الأقراص الدائمة**، لذا تُحفظ الجلسة والصور وقاعدة البيانات على قرص مؤقت. تعيش الجلسة بين عمليات الإيقاف والتشغيل (cold start)، لكنها **تُمسح عند كل إعادة نشر (redeploy)** — ستحتاج مسح رمز QR من جديد.
> إذا أردت حفظاً دائماً عبر إعادة النشر، استخدم خطة **Starter** وأعد إضافة القرص التالي إلى `render.yaml`:
> ```yaml
>     disk:
>       name: ihsebli-data
>       mountPath: /data
>       sizeGB: 1
> ```
