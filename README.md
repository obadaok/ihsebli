# احسب لي 🤖

مساعد محاسبي يعمل عبر واتساب لمتابعة عمليات شراء الذهب وتحويلات البنك.

## التشغيل محلياً

يتطلب: Node.js 18+ و tesseract (مع لغتي ara و eng).

```bash
npm install
npm run dev
```

امسح رمز QR المعروض من واتساب (الإعدادات ← الأجهزة المرتبطة).

## التشغيل على Render

1. ارفع هذا المشروع إلى GitHub.
2. في Render: **New → Blueprint** واختر المستودع.
3. `render.yaml` جاهز: سيبني Dockerfile، ويستخدم قرص `/data` لحفظ الجلسة والصور وقاعدة البيانات.
4. بعد النشر افتح رابط الخدمة (مثل `https://ihsebli.onrender.com`) — ستظهر صفحة فيها رمز QR لمسحه من الهاتف.
5. الجلسة تُحفظ على القرص، فلا تحتاج إعادة مسح إلا إذا مسحت البيانات.

> ملاحظة: أول اتصال قد يستغرق دقيقة حتى يظهر الرمز.
> خطة Render المجانية توقف الخدمة عند الخمول؛ الجلسة محفوظة على القرص وتعود عند التشغيل.
